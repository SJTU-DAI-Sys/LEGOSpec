# Qwen3-4B-DFlux

**Qwen3-4B-DFlux** is a **DFlux** speculative draft model for `[Qwen/Qwen3-4B](https://huggingface.co/Qwen/Qwen3-4B)`, trained with **[LEGOSpec](https://github.com/SJTU-DAI-Sys/LEGOSpec)** (*LEGOSpec: A Composable and Efficient Framework for Speculative Draft Design and Training*).

DFlux is a balanced general-purpose speculative draft architecture that combines:

- **SWA–GQA Hybrid Backbone with Block-Local Convolution**: 4 Sliding-Window Attention (`W = 512`) layers followed by 1 dense GQA full-attention layer, each equipped with a block-local grouped convolution (`kernel_size = 2`, `group_size = 16`) to preserve within-block dependencies across both short and long contexts while bounding historical KV cache growth.
- **Residual Corrector (R-Corrector)**: Computes parallel predecessor–successor residual corrections over the top-16 candidates while retaining full-vocabulary base logits, preserving the exact target distribution under rejection sampling.
- **Hierarchical Supervision**: Jointly trains the backbone with auxiliary forward KL / soft-CE loss (`weight = 0.2`) for candidate coverage and the final output with D-PAL loss (`weight = 1.0`, `rho = 0.3`) to directly optimize block-level acceptance length.

## Training Data & Setup

- **Dataset (1.4M samples total)**:
  - 900K samples from [Open-PerfectBlend](https://huggingface.co/datasets/mlabonne/open-perfectblend)
  - 300K samples from [Nemotron-Post-Training-Dataset-v2](https://huggingface.co/datasets/nvidia/Nemotron-Post-Training-Dataset-v2)
  - 200K samples from [WildChat](https://huggingface.co/datasets/allenai/WildChat)
- **Supervision**: Prompts are retained and responses are regenerated by `Qwen/Qwen3-4B` at `T = 1`.
- **Optimization**: Trained for 6 epochs on 16 NVIDIA H800 GPUs with global batch size 128, Adam (`lr = 6e-4`) and Muon (`lr = 0.01`).

## Usage

This checkpoint is a speculative draft model and requires its matching target model (`Qwen/Qwen3-4B`) for shared embeddings, output head, and verification.

Install [LEGOSpec](https://github.com/SJTU-DAI-Sys/LEGOSpec) and run speculative generation:

```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer
from legospec import LegoSpecConfig, LegoSpecModel

target_path = "Qwen/Qwen3-4B"
draft_path = "SJTU-DAI-Sys/Qwen3-4B-DFlux"

tokenizer = AutoTokenizer.from_pretrained(target_path)
target = AutoModelForCausalLM.from_pretrained(
    target_path, dtype=torch.bfloat16
).cuda().eval()

config = LegoSpecConfig.from_pretrained(draft_path)
draft = LegoSpecModel.from_pretrained(
    draft_path, config=config, dtype=torch.bfloat16
).cuda().eval()

text = tokenizer.apply_chat_template(
    [{"role": "user", "content": "Explain speculative decoding briefly."}],
    tokenize=False,
    add_generation_prompt=True,
    enable_thinking=False,
)
input_ids = tokenizer(text, return_tensors="pt", add_special_tokens=False).input_ids.cuda()
eos = target.generation_config.eos_token_id
stop_ids = [] if eos is None else eos if isinstance(eos, list) else [eos]

with torch.inference_mode():
    output_ids = draft.spec_generate(
        target,
        input_ids,
        max_new_tokens=128,
        stop_token_ids=stop_ids,
        temperature=0.0,
        top_p=1.0,
        seed=42,
    )

print(tokenizer.decode(output_ids[0, input_ids.shape[1]:], skip_special_tokens=True))
```

See the [LEGOSpec repository](https://github.com/SJTU-DAI-Sys/LEGOSpec) for SGLang serving and evaluation scripts.
